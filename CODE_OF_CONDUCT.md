# Code of Conduct

## Our pledge

We want this community space to be welcoming, helpful and harassment-free for
everyone, regardless of experience level or background.

## Expected behaviour

- Be respectful and constructive.
- Search before posting; keep issues on-topic.
- Accept that not every request can be implemented, and decisions rest with the
  maintainers.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Spam, advertising, or off-topic content.
- Sharing others' private information.
- Posting leaks, cracks, or asking for them.

## Enforcement

Maintainers may edit, hide, lock or delete content and block users who break these
rules. To report a problem, contact the maintainers privately or open a minimal
issue tagged appropriately.

This Code of Conduct is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/).
