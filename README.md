# pvp-corev3 — Community

Welcome! 👋 This is the **community space** for **pvp-corev3** — the Pacific Valley
Roleplay FiveM framework (MDT / CAD, Dispatch, Civilian system and more).

The source code is maintained privately, so **this repo is only for the community**:

- 🐞 **Report a bug** → [Open an issue](../../issues/new/choose)
- 💡 **Request a feature / share a wish** → [Open an issue](../../issues/new/choose)
- 🗣️ **Feedback, ideas & questions** → [Discussions](../../discussions)

## How it works

1. **Search first** — check the [existing issues](../../issues) and
   [discussions](../../discussions). If your idea already exists, give it a 👍
   instead of opening a duplicate.
2. **Open an issue** using one of the templates (Bug / Feature / Feedback), or
   start a **Discussion** for open-ended ideas and questions.
3. The maintainers triage, label and — if accepted — implement it in the private
   codebase. You'll get an update on the issue/discussion when it ships.

## Labels

`bug` · `enhancement` · `feedback` · `planned` · `in-progress` · `shipped` ·
`needs-info` · `wontfix` · `duplicate`

## Please be kind

This is a friendly space — be respectful and constructive. See the
[Code of Conduct](CODE_OF_CONDUCT.md). Off-topic, abusive or spam content will be
removed.
